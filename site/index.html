Fragments
Can a language model learn a language from its specification alone?

Each year we publish a new fragment of a language in Montague's sense: a grammar, invented words, rules that map sentences to logic, and a few small models. Systems parse it, interpret it and reason in it. Every answer is checked by a parser, a model checker or a theorem prover. No fragment has ever been seen in training.

Why

A model in practical use is often handed rules it has never seen: a style guide, a domain ontology, an in-house format. We want to know whether it follows such a specification or falls back on what it already knows. Most benchmarks cannot tell these apart, because the grammar, the words or the logic were in the training data. COGS and SLOG train the grammar in; MTOB gives a model an informal grammar book; RuleTaker and ProofWriter state rules over a language the model already speaks. If the language is familiar, a right answer does not show the rules were used.

Fragments removes the confound by construction. The grammar is new, the words are invented, and in one variant a familiar-looking word is given a contradicting meaning, so a system that trusts appearances goes visibly wrong.

A worked item

The same sentence from the practice fragment, as it appears in each of the three item types. Answers are one JSON object per line.

gesdam zispam gigup wonbis

answer

{"grammatical": true,
 "tree": "[S [NP [Det gesdam] [N zispam]]
          [VP [TV gigup] [NP [PN wonbis]]]]"}

checked by the parser

interpret

gesdam zispam gigup wonbis

answer

{"lfs": ["! [X] : (zispam(X) =>
            gigup(X,wonbis))"],
 "truth": [{"M1": false, "M2": false}]}

checked on M1, M2 and on models we withhold

infer

premises: gesdam zispam gigup wonbis
          zusdit zispam mippos
conclusion: zusdit zispam gigup wonbis

answer

{"label": "entailment",
 "lfs": {...},
 "certificate": {"proof": "..."}}

label and certificate checked by Prover9

Any logical form equivalent to the gold counts; nothing is string-matched. For a neutral inference the certificate is two models of the premises in which the conclusion differs. For ambiguous sentences the gold is a set of readings.

Four variants of every item

Every item has twins with the same abstract tree. Consistency across them is what the task measures.

nonce

Invented words, the default. Rules out lexical memorisation.

gesdam zispam gigup wonbis

english

The same trees with English words. Shows how much comes from familiar-language priors.

every cat likes Tam

scrambled

The same rules in an unnatural word order. Is the grammar read or assumed?

wonbis gigup zispam gesdam

counter-English

Nonce words, but the determiners meaning every and no have swapped meanings. A system that trusts how words look fails here; the drop from nonce to counter is the headline number per system.

gesdam = \P.\Q. ~exists x (P(x) & Q(x))

What is hard, in order

Items are tagged by phenomenon level and scores are reported per level. FraCaS sections give the template.

1
Quantification: every, some, no 2027

Negation and monotonicity 2027

Pronouns and donkey sentences, with a dynamic semantics
5
Plurals and comparatives
6
Intensional contexts, with worlds in the models

How to take part

Give the four specification files and the item file to your system; return one JSON line per item. That is the whole interface. We ship a prompting baseline that does exactly this, so a submission can be as small as one model run.

TrackWhat it means
model alonethe model's outputs from the specification in its context
model with toolsthe model with a prover, or with code it writes itself

Each submission declares its system type (prompted model, prover loop, program synthesis, neuro-symbolic, fine-tuned) and comes with a short experiment report. Results are reported by type rather than on one leaderboard. This is not a competition: several submissions per team and negative results are welcome. In an optional builder/breaker round, modelled on Voight-Kampff, you may submit new items with gold; items that pass our checker are run against all other systems.

Gold is never annotated; it is computed from the specification, and the generator and its seed are published after each cycle. The specification itself, scored as a system, gets 100% by construction and appears in every table as the ceiling, next to a human baseline from a linguistics seminar.
